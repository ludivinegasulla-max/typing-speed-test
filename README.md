# Typing Speed Test

## Description

Typing Speed Test est un exercice réalisé en HTML, CSS et JavaScript qui permet de mesurer la vitesse et la précision de frappe d'un utilisateur. Un texte est affiché aléatoirement et l'utilisateur doit le reproduire le plus rapidement possible sans faire d'erreur.

## Fonctionnalités implémentées

* Affichage d'au moins 5 textes différents à reproduire aléatoirement
* Champ de saisie pour l'utilisateur
* Coloration des caractères corrects et incorrects
* Timer automatique au premier caractère tapé
* Calcul du WPM
* Calcul du taux de précision
* Affichage des résultats
* Bouton recommencer

## Bonus

* Ajout d'un son à chaque erreur de frappe

## Languages utilisés

- HTML
- CSS
- JavaScript

## Lancement du projet

1. Ouvrir le fichier "Typing-Speed-Test" dans Visual Studio Code ou autre éditeur de code compatible
2. Ouvrir le fichier index.html dans un navigateur web grâce au bouton "Go Live"
